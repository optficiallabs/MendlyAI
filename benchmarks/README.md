# MendlyAI Benchmark Examples

This folder contains small, public benchmark cases for evaluating MendlyAI developer utilities.

The benchmark is intended to measure practical behaviour across areas such as API validation, privacy-safe logging, access-control checks, dependency changes, missing tests, and release readiness.

## Data Rules

All examples must be synthetic, de-identified, properly licensed, or independently created. Do not include real patient records, confidential healthcare information, credentials, tokens, production logs, or restricted third-party data.

## Suggested Evaluation Fields

Each benchmark case should describe:

- case identifier;
- category;
- input;
- expected outcome;
- reason for the expected outcome;
- severity or review priority where relevant.

The initial benchmark is deliberately small and transparent so that contributors can extend it over time.
