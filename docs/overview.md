# MendlyAI Documentation Overview

MendlyAI is an open healthcare technology project focused on clinical documentation, triage workflows, structured medical information, shift handovers, secure connected-care workflows, and reusable developer utilities.

## Documentation Goals

The documentation in this repository is intended to help developers, researchers, healthcare technology teams, and contributors understand the project structure, development approach, testing expectations, security principles, and planned modules.

## Core Principles

- Keep healthcare professionals in control of important clinical decisions.
- Use only synthetic, de-identified, properly licensed, or otherwise suitable data in public examples.
- Protect sensitive information through clear access, logging, validation, and security practices.
- Keep modules transparent, testable, and reusable.
- Document important interfaces and assumptions clearly.

## Planned Documentation

Future documentation will cover installation, clinical data validation, API interfaces, testing, security, release procedures, developer workflows, and contribution guidance.
