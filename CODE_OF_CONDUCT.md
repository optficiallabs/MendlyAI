# Contributor Code of Conduct

## Our Commitment

We are committed to providing a respectful, professional, inclusive, and collaborative environment for everyone participating in the MendlyAI project.

This applies to developers, researchers, healthcare professionals, students, maintainers, reviewers, documentation contributors, and community members.

## Expected Behaviour

We expect contributors to:

* communicate respectfully;
* provide constructive feedback;
* focus discussions on technical and project matters;
* respect different levels of experience;
* welcome new contributors;
* acknowledge mistakes and correct them;
* respect privacy and confidentiality;
* and work in a manner that supports the safety and quality of the project.

## Unacceptable Behaviour

The following behaviour is not acceptable:

* harassment;
* discrimination;
* personal attacks;
* threats;
* abusive or insulting language;
* deliberate disruption;
* sharing private information without permission;
* publishing confidential healthcare information;
* inappropriate use of project communication channels;
* or repeated behaviour that prevents productive collaboration.

## Healthcare and Privacy Responsibility

Because this project relates to healthcare software, contributors must take additional care with privacy and security.

Do not share:

* patient-identifiable information;
* real medical records;
* confidential hospital data;
* credentials;
* private keys;
* restricted third-party data;
* or other sensitive information.

## Technical Discussions

Technical disagreement is normal and welcome.

When discussing different approaches:

* explain the reasoning;
* provide evidence where possible;
* focus on the code or proposal rather than the person;
* remain open to alternatives;
* and accept maintainer decisions once a discussion is concluded.

## Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

Maintainers may:

* provide a warning;
* remove inappropriate content;
* restrict participation;
* temporarily suspend participation;
* or permanently remove a contributor from project spaces.

The response will depend on the seriousness and frequency of the behaviour.

## Reporting Concerns

Concerns about conduct may be reported privately to:

**[contact@optficial.ai](mailto:contact@optficial.ai)**

Reports will be reviewed as confidentially as reasonably possible.

## Scope

This Code of Conduct applies to:

* GitHub Issues;
* Pull Requests;
* Discussions;
* code reviews;
* project documentation;
* project meetings;
* and other official MendlyAI community spaces.

## Our Goal

The goal is simple: maintain a professional environment where people can contribute useful work, ask questions, disagree constructively, learn from one another, and improve healthcare software together.
